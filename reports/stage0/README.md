## Station identity review before treatment assignment

The table contains 23 repeated-name earlier/later ID pairs involving 23 later IDs opening in 2022–2024. See `station_identity_candidates.csv`. Distances compare the median of quarterly projected positions for each ID; missing historical coordinates remain missing. These are possible replacements or renumberings, not automatically confirmed duplicates. Different names can also conceal replacements, so the list is not exhaustive. Official opening-year counts are counts of IDs, not necessarily net additions to physical station sites. Resolve these candidates before freezing the treatment-source list; no IDs have been merged or dropped on this basis.

## Reproduction

```powershell
python -m pip install -e '.[dev]'

```

For an existing verified download, use `--offline`. URLs and SHA256 hashes for both downloaded archives and extracted CSVs are pinned in `data/manifest.json`. Discovery uses Indego's official public WordPress media index because the current data-page HTML lists stale 2017 downloads. Raw inputs are ignored by Git.
