# Indego station impact

1. **Question:** Do new bike-share stations increase local ridership or shift trips from existing stations?
2. **Data:** Public Indego trip data from 2022–2024.
3. **Method:** Preregistered stacked DiD on a 1 km grid.
4. **Result:** Area ridership **~+11%** (95% CI **+1.5% to +22%**); existing stations **~−8%** (95% CI **−16% to −0.2%**), consistent with partial diversion.
5. **Limitation:** About **56% power to detect a +10% effect**; the effect size remains imprecise.
